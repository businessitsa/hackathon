# Judging criteria

| Criterion | Suggested weighting |
| --- | --- |
| Relevance to the spaza shop challenge | 25% |
| Effective use of Interledger or Open Payments | 25% |
| Innovation and creativity | 15% |
| Usability and accessibility | 15% |
| Technical execution | 10% |
| Feasibility and potential impact | 10% |

:::tip
Teams will not be judged purely on polish. A smaller, well-considered working
solution may perform better than an ambitious but incomplete idea.
:::
