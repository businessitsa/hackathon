# Technology and resources

## Core technology

Teams will be introduced to:

- [Interledger Protocol](https://interledger.org/developers/get-started/)
- [Open Payments](https://openpayments.dev/)
- [Rafiki](https://rafiki.dev/)
- Payment pointers and wallet addresses
- Relevant APIs and sandbox environments

## Supporting tools

Teams may also use:

- JavaScript or TypeScript
- Node.js
- React, Next.js or another front-end framework
- GitHub
- Figma
- Postman
- Database and hosting tools of their choice

## Important technical requirement

:::warning
Each project should demonstrate a **meaningful connection to Interledger or
Open Payments technology**. A standard payment application with no clear use
of the provided technology would not meet the core challenge requirements.
:::
