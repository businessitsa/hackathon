# What teams must submit

Each team should submit:

- A short project description
- The problem or use case selected
- A working or partially working proof of concept
- A GitHub repository or technical files
- A short demonstration video or live demonstration
- A five-to-seven-minute pitch presentation
- A summary of how Interledger or Open Payments was used
- Known limitations and recommended next steps

A submission template will be linked from the
[Technology & Resources](./technology.mdx) page once it is ready.
